# 🚀 Инструкция по запуску YouTube Screenshot Tool

## Способ 1: Astro приложение (рекомендуется)

### Установка и запуск:
```bash
# Клонирование репозитория
git clone <your-repo-url>
cd youtube-screenshot-tool

# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Открыть в браузере
http://localhost:4321
```

### Сборка для продакшена:
```bash
npm run build
npm run preview
```

## Способ 2: Standalone HTML файл

Просто откройте файл `youtube-screenshot-standalone.html` в любом современном браузере. 
Никаких дополнительных установок не требуется!

## 📱 Использование

1. **Вставьте ссылку** на YouTube видео
2. **Выберите качество** скриншота  
3. **Нажмите "Сделать скриншот"**
4. **Скачайте или скопируйте** результат

## 🌐 Поддерживаемые URL форматы

- `https://www.youtube.com/watch?v=VIDEO_ID`
- `https://youtu.be/VIDEO_ID`
- `https://www.youtube.com/embed/VIDEO_ID`

## 🎨 Качество скриншотов

- **Максимальное** (1280x720) - рекомендуется
- **Стандартное** (640x480)
- **Высокое** (480x360)
- **Среднее** (320x180)

## 💡 Совет

Для лучших результатов используйте **максимальное качество** и современный браузер с поддержкой Canvas API.
